14. Tie-breaking Rule Precedence — Explicit Order
The three rules are applied in strict sequential precedence:
- **Rule 1:** Among all cells sharing the minimum cost, select the cell with the maximum allocatable quantity (`min(remaining_supply[i], remaining_demand[j])`). If this produces a unique winner, allocate there.
- **Rule 2:** If Rule 1 produces multiple winners with equal maximum quantity, prefer the cell where `remaining_supply[i] >= remaining_demand[j]`. If this produces a unique winner, allocate there. If multiple cells qualify, take the first in row-major order (`sorted(preferred)[0]`).
- **Rule 3:** If Rules 1 and 2 both fail to resolve the tie, apply index order: `sorted(candidates)[0]` — left-to-right, top-to-bottom. This is handled as an explicit `else` branch inside `allocation()`, not inside `tie_breaking()`.
